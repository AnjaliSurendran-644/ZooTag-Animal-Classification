# ZooTag-Animal-Classification
Deep learning animal classification system using TensorFlow and MobileNetV2

## Overview
ZooTag is a deep learning image classification system developed using TensorFlow and MobileNetV2 to classify zoological specimens into seven animal categories.

## Technologies
- Python
- TensorFlow
- Keras
- MobileNetV2
- Google Colab

## Features
- Transfer learning
- Data augmentation
- CNN fine-tuning
- Early stopping
- Learning rate scheduling
- Model evaluation using precision, recall, F1-score and confusion matrix

## Results
- Test Accuracy: 88.98%
- Validation Accuracy: 88.61%
